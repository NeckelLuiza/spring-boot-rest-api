# Spring Boot REST API

API REST desenvolvida em **Java e Spring Boot** para cadastro e persistência de usuários em banco de dados PostgreSQL.

O projeto utiliza uma estrutura em camadas, separando controllers, services, repositories, entities e DTOs.

## Funcionalidades

* Cadastro de usuários através de endpoint REST
* Validação de nome, e-mail e senha
* Persistência de dados em PostgreSQL
* Geração de identificadores UUID
* Definição de tipos de usuário
* Tratamento básico de exceções
* Modelagem de relacionamento entre usuários e pontos geográficos

## Tecnologias

* Java 21
* Spring Boot
* Spring Web
* Spring Data JPA
* PostgreSQL
* Maven

## Contexto

Projeto desenvolvido durante a graduação em **Ciência da Computação** como atividade prática para aplicação de conceitos de APIs REST, arquitetura em camadas, persistência de dados e integração com banco de dados relacional.
